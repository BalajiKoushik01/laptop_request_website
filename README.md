# Student registration form — interface demonstration

This repository is a **frontend-only practice project** using HTML, CSS and JavaScript. It demonstrates input validation, focus states, responsive layout and form feedback.

**It is not an official laptop distribution scheme.** It has no server, database, verified sponsoring institution or application processing system. No registration is submitted or stored. Do not type real registration numbers, contact details or other personal information into this demo.

## Run

Clone the repository, then open `index.html` in a browser. No build tooling is required. Google Fonts and Font Awesome are loaded from CDNs when an internet connection is available.

## What works

The client-side code validates five example fields, displays inline errors and presents a local success state once the form is complete. That state means **only that the example passed local validation**. It does not mean an application was accepted. Data is not sent to a server or logged to the browser console.

## Before using this for a real application

A legitimate institution would need to identify the program and eligibility criteria, provide an authorised backend and privacy notice, enforce server-side validation, limit access to submitted records, set retention/deletion policies and test accessibility. Adding a submission endpoint without those requirements would create a misleading data-collection system.
